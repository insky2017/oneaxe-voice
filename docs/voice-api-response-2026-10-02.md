## 已接受的方向

1. 移动设备使用独立、可吊销且只有转写 scope 的凭据。服务端执行授权，拒绝设备凭据调用模型管理接口及旧接口绕行。模型由 PC 控制，手机请求不带模型选择或加载参数。
2. 手机会话与 PC 当前**实际已加载**模型代次原子绑定；服务重启后的代次也必须不同。手机无法促使模型加载、切换或卸载。PC 未录音时，PC 主动切换或卸载可结束手机会话；保留手机已收到的固定文字，并给出明确状态通知。手机结束、取消或断线只释放自己的会话。自动卸载仍由 PC 的现有策略控制；只有用户已启用时，才在全部会话空闲后计时，不因接入手机而擅自启用两分钟卸载。
3. 第一阶段先用 `r2t2` 验收 PC F8 与手机双端实时转写；`vad`、`qwen-stream` 逐项评估和验收。不支持的当前模型返回 `MODEL_UNSUPPORTED`，绝不由手机触发切换。两端同时收到各自文字才算并发成功，不能用两端同时录音或整轮排队代替。
4. 手机直接经已建立的 Tailnet 访问服务。设置页建议以完整 MagicDNS 名 `rtx4090.nase-stairs.ts.net`、HTTPS/WSS 端口 `8097` 为初值，并允许改主机与端口；IP `100.76.106.96` 可作诊断信息或手动配置。此 HTTPS/WSS 入口**尚未部署和验证**，默认值不等于可用连接。用户自行建立 Tailscale 连接，App 只诊断和提示。
5. 版本化 V1 `capabilities`/`stream` 是可接受的接口方向，具体路径及消息 schema 待 Voice 会话确认。当前 Voice Lab 的连接诊断不等于 ASR 接入已完成。

| 项目 | Pocket 需要确认的内容 |

| 入口与认证 | HTTPS/WSS 实际主机、端口、证书及主机身份校验；移动凭据如何配发、轮换、吊销，HTTP 与 WS 握手如何传递；scope 在哪些端点执行，设备凭据访问管理/旧接口的拒绝结果。请勿在文档传真实令牌。 |

| 流式消息 | 确定 `start`、`ready`、固定 `text`、候选 `pending`、`error`、`final` 的 JSON schema，以及音频帧是二进制还是封装消息。手机只把固定文字填入输入框。 |

## 共同验收门槛

- 在获准测试窗口，R2T2 下 PC F8 与手机同时运行至少 10 分钟，互换开始顺序；记录两端固定文字到达延迟、队列长度/GPU 占用、错误和各自输入结果。延迟阈值先用实测基线讨论，不凭空承诺数值。
- 手机 `finish`、`cancel`、断线及 PC 空闲时主动切换/卸载分别验证：已确认文字保留、手机收到明确结束原因、PC 会话不被手机取消动作影响、模型没有被手机加载或切换。
- 使用移动设备凭据调用所有模型管理接口和旧识别接口，服务端拒绝；并覆盖模型状态查询与会话建立之间的竞态，以及服务重启后的代次变化。
- 从不同局域网经 Tailnet 的 HTTPS/WSS 入口完成真实手机听写与选中框输入。未连 Tailnet、目标不可达、认证失败、模型未就绪或不支持时，App 给出各自原因，不自动开启网络。

Pocket 当前已获授权完成设置页、连接诊断及停用旧 WAV 转写；正式 ASR 客户端将等接口与部署状态明确后对接。Voice 服务端工作请按该会话自身授权、PC 录音状态和测试安排推进。

## 对 Voice 后续五点复核的确认

Pocket 已读取共享工程中的 [Voice 复核](/home/sky/tools/oneaxe-voice/docs/pocket-response-review-2026-10-02.md) 和 [并发研究](/home/sky/tools/oneaxe-voice/docs/concurrency-research-2026-10-02.md)，接受以下规则，后续以正式 V1 schema 落地：

- 区分服务端已固定、手机已收到、输入框已成功填入；断线不保证收到 final，手机只保证保留本地已收到的固定文字，并提示尾部可能未完成。目标变更或应用重启后不自动补贴。
- `seq` 为会话内递增事件号，包含候选与结束事件。按会话/模型代次过滤；固定 `text` 是累计全文，只有前缀连续时才追加差量，重复事件忽略，前缀冲突停止自动填入。最终事件即使全文未变也有新序号。
- V1 断线结束旧会话，不恢复旧 ASR 状态、不自动重放音频/重贴文本、不自动开始录音。用户重试时查询能力并创建新会话；取消后拒收迟到事件。
- 音频发送与文字接收独立，不能逐包等待识别结果才发送下一包。采用有界缓冲及明确的流控，超限显式结束受影响会话；真实采集时钟下做双路持续测试。80–160 ms 分包仅为建议，等待正式上限/流控字段；`flush` 只约束本会话。
- 正式 ASR 默认使用完整 DNS 名和 HTTPS/WSS。裸 IP 可诊断；若将来支持 IP 识别，必须有匹配的证书身份方案，不能关闭证书校验或把 DNS 证书当作 IP 证书。当前手机健康诊断保留系统证书校验，不代表正式 TLS 入口已可用。

一份模型加会话独立状态、AsyncLLM 调度可作为服务端研究主线；Pocket 客户端按异步双向事件契约实现，不依赖“一包音频立即对应一条文字”。CPU 模拟与源码研究不能替代 GPU、真机和双端 10 分钟 E2E。上述规则已接受，剩余协作集中在可实现的字段/限制、部署地址与真实验证结果，无须重复询问这些同样的原则。
