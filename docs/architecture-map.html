听到了声音但没看到文字，从哪里查
  • 没有录音：查看 desktop-status 的模式、预热状态与 DJI 音源；R2T2 冷启动未完成前不会开始采集。
  • 字幕有候选、输入框没字：候选可能尚未固定；固定文字也可能在菜单打开时等待交付。
  • 只复制不粘贴：原窗口或焦点已变化，本轮触发输入保护；不会自动补贴到新窗口。
  • 已发送但目标框没收到：这里表示已执行粘贴按键，任意目标应用是否接收仍需单独核对。
03 / 会话与算力

共享权重，隔离每一路状态

固定保留一个 PC 名额与一个手机名额。每路顺序处理、最多一个模型步骤在途，由 vLLM 连续批处理两路请求。

手机建立过程→能力查询→设备 Bearer→绑定实例 + 模型代次→收到 ready→采集 / 发送与接收并行

额度控制积压

audio_send_limit = processed + 32000。只在累计已发送样本不超额度时发包；未发送缓存最多 2 秒。超限结束本轮并保留已确认文字。

序号控制文字顺序

单发送队列分配 seq，允许合并中间快照。客户端校验会话身份、序号和固定前缀，只追加新后缀。

取消只清理本路

手机取消、断线、结束或凭据吊销，只释放对应状态与请求。共享 worker 整体故障会影响两端；PC 主动切模型也会结束手机。

04 / 谁可以加载、占用和释放

模型状态与会话占用分开判断

05 / 进程与外部依赖

三个用户服务，流式推理独立进程

桌面与托盘负责交互，API 拥有引擎生命周期；流式模型运行在子进程中。运行时音频不会发往云端 ASR。
