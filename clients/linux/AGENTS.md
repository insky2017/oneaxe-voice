# 开发约定

- 简体中文交付。README 是入口，设计与验证证据放 docs/。
- 本工程是独立客户端；不修改 OneAxe Voice 服务端代码或接口。必要服务端改动须先获用户确认。
- 复用移动 V1，只调用 capabilities 和 dictation/stream；没有模型管理权限。
- 默认可配 F9，不覆盖本机 F8 或其他冲突快捷键。
- 首版仅 Tailnet HTTPS/WSS；公网仅规划。
- 凭据仅存系统密钥环；失败只保存在本次内存，禁止明文持久化、日志、命令参数或 Git。
- 默认不保存录音和长期转写；取消先关交付门，断线不恢复音频、不补贴。
- 不重启 VPlus，不修改共享模型。不干扰用户正在进行的本机录音。
- 本机与 e15l 分别安装测试，模拟测试和真实服务测试分别记录。用户已验证 tmux，不重复测试。
- 子代理统一 gpt-6.1-sol / xhigh。

## 测试

- 优先用真实依赖验证关键端到端流程，其次验证 API、音频与消息边界。
- 保留脱敏真实音频及已确认预期作为黄金样例；不以测试数量或覆盖率作为交付标准。
- 默认不新增单元测试；仅对复杂算法、关键状态机或安全逻辑按需补充。
